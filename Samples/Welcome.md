# Welcome to Markdown

A quiet place to **read**, *write* and ~~fiddle with~~ craft Markdown. Press `⌘1`, `⌘2` or `⌘3` to switch between **Edit**, **Split** and **Preview**.

> Simplicity is the ultimate sophistication.
> — Leonardo da Vinci

## Lists

- Native, fast and lightweight
- Liquid Glass toolbar and controls
  1. Edit
  2. Split
  3. Preview
- QuickLook previews in Finder

### Tasks

- [x] Open a Markdown file
- [x] Preview it with the space bar
- [ ] Write something wonderful

## Code

Inline `code` and fenced blocks:

```swift
struct Greeting {
    let name: String
    func callAsFunction() -> String { "Hello, \(name)!" }
}
```

## Tables

| Shortcut | Action          | Mode    |
|:---------|:----------------|--------:|
| ⌘1       | Show editor     | Edit    |
| ⌘2       | Side by side    | Split   |
| ⌘3       | Show preview    | Preview |
